## IPL Data Analysis Dashboard using Power BI

## Project Overview

This project analyzes Indian Premier League (IPL) cricket data using Power BI.

## Objectives

- Analyze team performance.
- Compare batsmen and bowlers.
- Identify top run scorers and wicket takers.
- Visualize match results and winning trends.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV

## Dashboard Features

- Team performance analysis
- Top batsmen and bowlers
- Match and season analysis
- Interactive charts and filters
